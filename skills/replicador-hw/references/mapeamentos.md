## Como resolver o ID de uma pasta

O nível 1 (`Arquivo de Edição `) e o nível 2 (nichos) têm **ID fixo** — use a
tabela abaixo. Produto e subpasta resolvem por nome em tempo de execução com
`search_files`:

```
parentId = '{id_do_nicho — ver tabela}' and title = 'MemoPryl'
→ pega o ID do produto

parentId = '{id_produto}' and title = 'OT'
→ pega o ID onde criar a pasta da demanda
```

Confirmar com `get_file_metadata` antes de criar. Se algum nível não existir,
**criar** (mimeType `application/vnd.google-apps.folder`) — a árvore é nova e
produto novo entra assim, sem precisar pedir URL ao usuário.

⚠️ A árvore foi criada em 08/08/2026 e o índice de busca do Drive pode demorar a
propagar. Se `search_files` não achar uma pasta que você sabe que existe, cair
para navegação pelo filesystem local no caminho acima.

## Padrão de nomenclatura das pastas

**[OT] e [OF] (com prefixo de tipo):**
```
[DDMMAA][OT] TIPO_VARIACAO [CLIENTE] - SUBTIPO [Squad]
```
Exemplo: `[250526][OT] ML_09_PG [NT] - Gustavo [Squad B]`

**[OT] formato curto (sem tipo/subtipo, produto entre colchetes):**
```
[DDMMAA][OT] VARIACAO_INICIAIS [Produto] [Squad]
```
Exemplo: `[230726][OT] 05_JV [Vigorox] [Squad]`

**[DTC]:**
```
[DDMMAA][DTC] {nomenclatura-original}
```
Exemplo: `[250526][DTC] Squad Comercial - Gelatide > JellyLean - Aff Wifi`

**Regra da barra:** `ML/09_PG` vira `ML_09_PG` (substituir `/` por `_`)

**Data `DDMMAA`:** dia em que a demanda entrou no canal #demandas-edição.

**Squad desconhecido:** usar `[Squad]` como placeholder no nome.
